# 08 — Explainability

Every action the system takes must be explainable in two columns: **what Crown said** and
**what the system did, and why it differs**. This is a build requirement, not a reporting
nicety — a decision that can't produce its record isn't allowed to execute.

## The decision record

Written for every plan, approval request, order, exit, skip, and reconciliation outcome.

```jsonc
{
  "decision_id": "uuid",
  "at": "ISO-8601",
  "kind": "plan|entry|exit|trim|stop_change|skip|expire|reconcile|halt",
  "crown": {
    "letter_date": "2026-06-22",
    "thesis_id": "gold-bearish-2026-06",
    "crown_position_id": "gld-385-375-put-spread-jun26",
    "said": [{"page": 4, "quote": "invalidation = reclaim of $391–392 zone"}],
    "structure": "GLD Jun26 385/375 put spread, ~$3.00 debit",
    "multiplier": null
  },
  "system": {
    "action": "skip",
    "deviation_tier": 1,
    "deviations": [
      {"what": "multiplier defaulted to 0.25", "why": "letter printed no sizing", "constraint": "missing_data"}
    ],
    "alternatives_rejected": [
      {"candidate": "GLD 385/375 as written", "reason": "risk $300/unit > $18.75 budget"},
      {"candidate": "GLD 385/380 put spread", "reason": "risk $155/unit > $18.75 budget"},
      {"candidate": "GLL (−2x gold)", "reason": "leveraged inverse; horizon > max hold"}
    ],
    "sizing": {"budget": 18.75, "best_risk_per_unit": 155, "units": 0},
    "exit_plan": null,
    "guardrails_checked": []
  },
  "inputs": {"prices": {"GLD": 386.2}, "data_asof": "...", "extractor_version": "...", "config_hash": "..."},
  "approval": {"level": "L0", "requested_at": "...", "response": "yes|no|timeout", "by": "telegram"},
  "outcome_ref": "order/fill ids"
}
```

Records are append-only (SQLite), and every record carries the config hash and extractor
version so any past decision can be reproduced.

## Memos (what you read on your phone)

One memo per decision that needs you or that you'd want to know about. Lead with the
verdict, then the two columns, then the numbers.

```
SKIP — Gold bearish (Crown, 6/22)
Crown: GLD 385/375 put spread @ $3.00. Out if GLD reclaims 391–392.
Us:    nothing fits. Budget $18.75 (no multiplier printed → 0.25 default).
Tried: Crown's spread ($300/unit), 385/380 spread ($155/unit),
       GLL (leveraged inverse, horizon too long).
Binding constraint: sleeve size.
```

```
EXIT (executed, no approval needed) — SPY long, thesis "equities constructive"
Crown thesis invalidation fired: SPX closed 7,438 < zero-gamma 7,457 (p.6).
Sold 4 SPY @ 742.10. P&L −$31 (−0.4R). Thesis → invalidated.
```

## Reports

- **Weekly scorecard** — Crown's book vs ours, position by position: held / skipped /
  substituted, and P&L for each (doc 09).
- **Deviation log** — every tier-1/2 deviation in the week with its attributed P&L effect.
- **Open-book view** — each open position with its thesis, Crown's current status, our
  exit plan, which exits are broker-side vs agent-side, and distance to each.
- **Skip log** — every Crown position we didn't take and the binding constraint. Over time
  this shows which constraint costs the most (e.g. "no spreads" vs "sleeve size").

## Rules

- Quotes come from the extraction; since letters are images, each quote also stores the
  page number so it can be checked against the page image.
- A memo may summarize but may not state anything that isn't in the decision record.
- Numbers in memos are rendered by code from the record, never generated by the LLM.
